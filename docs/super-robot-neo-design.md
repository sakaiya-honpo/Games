# スーパーロボット大戦Neo式 3D戦術シミュレーション ゲーム設計書

## 1. コンセプト

スパロボNeoの3D自由移動マップをベースに、ユニットサイズ差による物理的影響、曲射攻撃による地形越え射撃、FF12ガンビット式のAIプログラミングを融合した戦術シミュレーションゲーム。

プレイヤーは「パイロットへの指示書（ガンビット）」を事前に組み、戦闘はセミオートで進行する。介入タイミングを見極める"指揮官の判断"がゲームの核。

### 1.1 ジャンル定義

セミオートマチック3Dタクティカルシミュレーション

### 1.2 ターゲット

- SRPGファン（スパロボ、FE、FFT経験者）
- プログラミング的思考を楽しめるプレイヤー（Gladiabots、Autonauts層）
- メカカスタマイズ好き

## 2. コアメカニクス

### 2.1 3Dマップシステム（Neo式）

#### マップ構造
- **グリッドレス自由移動**: Neo同様、ユニットは円形の移動範囲内を自由に移動
- **高低差**: 地形に高度(0〜255)を持たせ、崖・丘・ビルなどを表現
- **遮蔽判定**: ユニット中心から目標中心へのレイキャストで遮蔽率を算出

```
マップデータ構造:
Map {
  terrain_mesh: 3D地形メッシュ
  height_map: float[width][depth]    // 各地点の高度
  cover_objects: CoverObject[]       // 遮蔽物（破壊可能/不可能）
  zones: Zone[]                      // 特殊地形ゾーン（水域、溶岩、etc）
}
```

#### 移動システム
- 移動力は「距離」ベース（Neo準拠）
- 高度差による移動コスト増（上り+50%、下り-20%）
- 飛行ユニットは高度差無視、ただし高度維持にENコスト

#### 視線・射線（Line of Sight）
- 射線はユニットの「頭部高度」から目標の「中心高度」へのレイで判定
- 遮蔽率: 0%（完全に見える）〜 100%（完全に隠れている）
- 部分遮蔽は命中率に反映（遮蔽率50% → 命中率-50%）

### 2.2 サイズシステム

#### サイズ区分

| サイズ | 代表例 | 占有半径 | HP係数 | 回避係数 | 遮蔽提供 |
|--------|--------|----------|--------|----------|----------|
| SS | 戦闘機、ドローン | 2m | 0.5x | 2.0x | なし |
| S | 人型小型機 | 5m | 0.8x | 1.5x | 小 |
| M | 標準人型機 | 8m | 1.0x | 1.0x | 中 |
| L | 大型機 | 15m | 1.5x | 0.6x | 大 |
| LL | 戦艦級 | 30m | 3.0x | 0.2x | 巨大 |

#### サイズ差の戦術的影響

1. **物理遮蔽**: 大型ユニットが小型ユニットへの射線を遮る
   - L以上のユニットの背後にいるM以下のユニットは遮蔽ボーナス取得
   - 味方の大型機を「盾」として運用する戦術が成立

2. **命中補正**: サイズ差による命中率修正
   - 大→小: -15%/サイズ差1段階（大きい武器は小さい敵に当てにくい）
   - 小→大: +15%/サイズ差1段階（大きい敵には当てやすい）

3. **踏み潰し判定**: LL以上のユニットがSS〜Sユニットの位置を通過時、踏み潰し攻撃発生
   - 回避判定あり、ただし回避失敗時は即撃墜

4. **投擲/搭乗**: LがS以下を投擲可能、LLがM以下を搭乗（甲板搭載）可能

5. **部位判定**: L以上は部位（頭/胴/腕L/腕R/脚/武装）を持ち個別に破壊可能
   - 脚部破壊 → 移動力半減
   - 腕部破壊 → 対応武器使用不可
   - 頭部破壊 → 命中率-40%、ガンビット精度低下

### 2.3 曲射攻撃システム

#### 攻撃の弾道分類

```
直射（Direct Fire）: 射線が必要。遮蔽の影響を受ける
  例: ビームライフル、実弾ライフル、格闘攻撃

曲射（Indirect Fire）: 射線不要。放物線で飛翔
  例: ミサイル、榴弾砲、迫撃砲

天頂射（Top Attack）: 真上から落下。屋根/天井以外の遮蔽無効
  例: 誘導爆弾、衛星レーザー、MAP兵器

制圧射（Suppression）: 範囲に継続ダメージゾーンを生成
  例: クラスター弾、ナパーム、ミノフスキー粒子散布
```

#### 曲射の仕様

- **最低射程**: 曲射武器には最低射程あり（近すぎると撃てない）
- **着弾遅延**: 発射から着弾まで1〜3フェイズの遅延（目標が移動する可能性）
- **散布界**: 距離に比例して着弾点がばらつく（精度パラメータ依存）
- **高度ボーナス**: 高所からの曲射は散布界縮小・射程延長
- **対空迎撃**: 曲射弾を迎撃可能な武器/スキルあり（CIWS等）

#### 曲射の戦術的意義

- 遮蔽に隠れた敵を攻撃可能 → 「隠れ得」を防止
- 着弾遅延があるため、予測射撃 or 移動制限との連携が必要
- 大型ユニット（散布界内に収まりやすい）に特に有効
- 味方巻き込みリスク → ガンビットでの友軍誤射防止が重要

### 2.4 ガンビットシステム（AI判定）

#### 概要

各ユニットに最大12個の「ガンビットスロット」を設定可能。
上から順に条件を評価し、最初に合致した行動を実行する。

```
ガンビット構造:
Gambit {
  condition: Condition    // IF: いつ
  target: TargetFilter    // WHO: 誰に
  action: Action          // DO: 何を
  enabled: bool           // ON/OFF切替
}
```

#### 条件（Condition）一覧

**自機状態**
- HP < X%  /  HP > X%
- EN < X%  /  EN > X%
- 弾数 < X
- 状態異常あり（指定可）
- 被ロック数 >= X（自分を狙っている敵の数）

**対象状態**
- 対象HP < X%
- 対象サイズ = X
- 対象が飛行中
- 対象が曲射武器装備
- 対象の射程内にいる / いない

**戦場状況**
- 味方 X 体以内に味方がいる（集団判定）
- 味方 X 体以内に味方がいない（孤立判定）
- 距離 < X / > X（対象との距離）
- 高度差 > X（対象との高度差）
- 遮蔽率 > X%（対象への遮蔽）
- ターン数 >= X

**複合条件**
- AND / OR で最大3条件結合

#### ターゲットフィルタ（TargetFilter）

```
対象種別: 敵 / 味方 / 自分
ソート基準: 最近距離 / 最低HP / 最高脅威度 / サイズ大 / サイズ小
追加フィルタ: サイズ指定 / 射程内のみ / 遮蔽なしのみ / 飛行中のみ
```

#### 行動（Action）一覧

**攻撃系**
- 武器指定攻撃（直射/曲射/格闘）
- 最大ダメージ攻撃（自動選択）
- 必中攻撃（最も命中率が高い武器）

**移動系**
- 対象に接近
- 対象から離脱
- 遮蔽へ移動（最寄りの遮蔽物の裏へ）
- 高所へ移動
- 味方大型機の背後へ移動（サイズシールド）

**支援系**
- 修理
- 補給
- 対空迎撃待機（CIWS自動発動モード）
- 援護防御待機（隣接味方への攻撃を肩代わり）

**特殊**
- 待機（何もしない）
- 指揮官に判断を返す（手動介入要請）

#### ガンビットの戦術例

```
# 前衛タンク（Lサイズ）のガンビット例
1. [自HP<20%]        → 自分  → 後退（味方方向へ）
2. [味方SS/SがM以内]  → 味方  → 援護防御待機
3. [敵が曲射発射]     → 自分  → 対空迎撃待機
4. [敵サイズSS/S]     → 敵最近 → 踏み潰し接近
5. [遮蔽率<30%]      → 敵最近 → 格闘攻撃
6. [遮蔽率>=30%]     → 敵最近 → 曲射攻撃（ミサイル）
7. [常時]            → 敵最近 → 最大ダメージ攻撃

# 後衛砲撃手（Mサイズ）のガンビット例
1. [自HP<30%]        → 自分     → 遮蔽へ移動
2. [敵がM以内]       → 敵最近   → 離脱
3. [敵サイズL以上]    → 敵最大   → 曲射攻撃（榴弾砲）
4. [敵遮蔽率>50%]    → 敵最低HP → 曲射攻撃（迫撃砲）
5. [敵遮蔽率<=50%]   → 敵最低HP → 直射攻撃（ライフル）
6. [常時]            → 自分     → 高所へ移動
```

#### 指揮官介入システム

- 各ターン開始時に「介入ポイント（CP: Command Point）」を取得
- CPを消費してガンビットを一時的にオーバーライドし手動指示可能
- 精神コマンド（熱血、必中、鉄壁等）もCPで発動
- CPの使い所が戦略の鍵 → 全自動か要所介入かのジレンマ

```
CP獲得:
- ターン開始: +3 CP
- 敵撃墜: +1 CP
- 味方被撃墜: +2 CP（窮地ボーナス）
- 指揮官スキル: 追加CP

CP消費:
- 手動移動指示: 1 CP
- 手動攻撃指示: 2 CP
- 精神コマンド: 2〜5 CP
- 緊急回避指示: 3 CP（攻撃をキャンセルして回避）
```

## 3. ターン進行

### 3.1 フェイズ構成

```
1. 指揮フェイズ（プレイヤー操作）
   - ガンビットの確認・修正
   - CP消費による手動指示の予約
   - 精神コマンドの発動
   - 出撃/撤退指示

2. 行動フェイズ（セミオート）
   - SPD順にユニットが行動
   - ガンビットに従い自動行動
   - 手動指示があればそちらを優先
   - 曲射の着弾処理（前ターン発射分）
   
3. 結果フェイズ
   - ダメージ処理、撃墜判定
   - 部位破壊判定
   - 状態異常付与
   - 経験値・資金獲得
   
4. 敵ターン（同様にガンビットで行動）
```

### 3.2 速度と行動順

- 各ユニットのSPDパラメータで行動順決定
- SPD差が大きい場合、1ターンに複数回行動可能
- SSサイズユニットは基本SPDが高く、LLは低い

## 4. ユニット設計

### 4.1 パラメータ

```
Unit {
  // 基本
  name: string
  size: SS | S | M | L | LL
  move_type: 陸 | 空 | 水 | 宇宙 | ホバー
  
  // ステータス
  hp: int           // 耐久力（サイズ係数適用後）
  en: int           // エネルギー
  armor: int        // 装甲値
  mobility: int     // 運動性（回避に影響）
  move: float       // 移動距離（メートル）
  spd: int          // 行動速度
  
  // 武装スロット
  weapons: Weapon[max_slots]  // サイズにより4〜8スロット
  
  // ガンビットスロット
  gambits: Gambit[12]
  
  // 部位（Lサイズ以上）
  parts: Part[]     // 頭/胴/腕L/腕R/脚/武装
  
  // パイロット
  pilot: Pilot
}
```

### 4.2 武器パラメータ

```
Weapon {
  name: string
  type: 直射 | 曲射 | 天頂射 | 格闘 | 制圧射
  damage: int
  accuracy: int         // 基本命中率
  range_min: float      // 最低射程（m）
  range_max: float      // 最大射程（m）
  ammo: int | null      // 弾数制限（nullならEN消費）
  en_cost: int          // EN消費
  spread: float         // 散布界（曲射のみ、m）
  impact_delay: int     // 着弾遅延フェイズ数（曲射のみ）
  aoe_radius: float     // 効果範囲（0なら単体）
  size_effective: Size[] // 有効サイズ（空なら全サイズ）
  interceptable: bool   // 迎撃可能か
  terrain: string[]     // 使用可能地形
}
```

### 4.3 パイロットスキル

パイロットはガンビットの条件・行動の幅を拡張するスキルを持つ。

```
スキル例:
- 先読み: 曲射着弾予測地点を表示（ガンビット条件に追加可能）
- 狙撃手: 直射の射程+30%、ただし移動後攻撃不可
- 統率: 周囲の味方のガンビット精度+10%
- 暴走: HP<25%時、ガンビット無視して最も近い敵に突撃
- CIWS適性: 対空迎撃の成功率+20%
- サイズ無視: サイズ差による命中補正を無効化
```

### 6.2 ガンビットエンジン

```python
class GambitEngine:
    def evaluate(self, unit, battle_state):
        for gambit in unit.gambits:
            if not gambit.enabled:
                continue
            if gambit.condition.evaluate(unit, battle_state):
                targets = gambit.target_filter.get_targets(unit, battle_state)
                if targets:
                    return GambitResult(
                        action=gambit.action,
                        target=targets[0],
                        gambit=gambit
                    )
        return GambitResult(action=Wait(), target=None, gambit=None)
```

### 6.3 弾道計算

```python
class BallisticCalculator:
    def calculate_arc(self, origin, target, weapon):
        distance = (target.pos - origin.pos).length()
        height_diff = target.pos.y - origin.pos.y
        
        launch_angle = self.optimal_angle(distance, height_diff, weapon)
        flight_time = weapon.impact_delay
        
        spread = weapon.spread * (distance / weapon.range_max)
        impact_point = target.pos + random_in_circle(spread)
        
        return Trajectory(
            origin=origin.pos,
            target=impact_point,
            angle=launch_angle,
            flight_time=flight_time
        )
```

### 6.4 遮蔽・射線判定

```python
class LOSCalculator:
    def calculate_cover(self, attacker, defender, battle_state):
        ray_origin = attacker.head_position()
        ray_target = defender.center_position()
        
        hits = battle_state.raycast(ray_origin, ray_target)
        
        cover_ratio = 0.0
        for hit in hits:
            if hit.object == defender:
                continue
            if hit.object.is_unit and hit.object.size >= Size.L:
                cover_ratio += 0.4  # 大型ユニットによる遮蔽
            elif hit.object.is_terrain:
                cover_ratio += hit.object.cover_value
        
        return min(cover_ratio, 1.0)
```

## 付録B: 用語集

| 用語 | 定義 |
|------|------|
| ガンビット | ユニットの自動行動ルール。条件→対象→行動の3要素で構成 |
| CP（コマンドポイント）| 指揮官がガンビットをオーバーライドするためのリソース |
| 曲射 | 放物線弾道で障害物を越えて着弾する攻撃。着弾遅延と散布界を持つ |
| 散布界 | 曲射攻撃の着弾点のばらつき範囲 |
| 遮蔽率 | 射線上の障害物による命中率低下の度合い |
| 部位破壊 | L以上のユニットの特定部位を破壊し機能を制限すること |
| サイズシールド | 大型味方ユニットの背後に位置することで遮蔽を得る戦術 |
| 天頂射 | 真上から落下する攻撃。通常の遮蔽を無視する |
| 制圧射 | 範囲に継続ダメージゾーンを生成する攻撃 |
